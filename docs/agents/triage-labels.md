# Triage labels

These labels map the engineering skills' canonical triage roles to this repository's issue workflow.

| Role | Label | Meaning |
| --- | --- | --- |
| Needs evaluation | `needs-triage` | A maintainer needs to assess the report. |
| Waiting for details | `needs-info` | More information is needed from the reporter. |
| Ready for an agent | `ready-for-agent` | The issue is specified well enough for independent implementation. |
| Ready for a person | `ready-for-human` | A person needs to make or guide the change. |
| Won't fix | `wontfix` | The issue will not be actioned. |

Use the existing label spelling exactly; do not create duplicate labels with alternate names.
